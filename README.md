# حساب كفاءة الري بالرش المحوري (بيفوت)

تطبيق ويب يعمل **أوفلاين** وقابل للتثبيت على سطح المكتب والجوال (PWA).

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub (مثلاً `pivot-efficiency`).
2. ارفع كل محتويات هذا المجلد إلى المستودع (index.html + sw.js + manifest.json + xlsx.full.min.js + مجلد icons).
3. من إعدادات المستودع → **Pages** → Source: **Deploy from a branch** → اختر `main` و `/ (root)`.
4. بعد دقيقة ستحصل على الرابط:
   ```
   https://USERNAME.github.io/REPO_NAME/
   ```

## التثبيت على الجهاز

- **ويندوز / ماك / لينكس (Chrome أو Edge):** افتح الرابط → أيقونة التثبيت في شريط العنوان أو القائمة ⋮ → «تثبيت التطبيق».
- **أندرويد:** افتح في Chrome → «إضافة إلى الشاشة الرئيسية» أو «تثبيت التطبيق».
- **آيفون:** افتح في Safari → زر المشاركة → «إضافة إلى الشاشة الرئيسية».

بعد التثبيت يعمل بدون إنترنت (ما عدا تصدير Excel إذا لم تُحمَّل المكتبة مسبقًا — وهي مضمّنة محليًا).
